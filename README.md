# AI 网文工作台

一款 Electron 桌面应用,用 AI 辅助创作**长篇中文网文/爽文**。数据全部保存在本地,支持接入任意 OpenAI 兼容大模型(智谱 GLM / DeepSeek / Kimi / Ollama 等)。

![技术栈](https://img.shields.io/badge/Electron%20%2B%20React%20%2B%20TypeScript-44-blue)

## 功能

- **书库管理**:多本书籍,每本书一个本地目录(`book.json` + 章节 JSON),可自定义书库位置
- **卷/章结构**:分卷管理章节,支持增删、排序、状态标记(待写/草稿/完成)
- **设定集**:人物卡(性格/背景/成长线)、物品图鉴(武器/丹药/阵法/功法/科技/魔法,含品级、获取方式与地点、持有者、阶段记录)、世界观(世界背景/力量等级体系/金手指/势力),生成时全部自动注入
- **AI 起名与生成**:角色 AI 起名(5 个候选一键建卡)、AI 生成完整物品卡(含名称/品级/效果/获取方式/地点)、**本章提取**——从你写好的章节里自动提取新物品归档(阶段性物品记录)
- **拆书扫书**(扫书工作区):导入 TXT(自动识别 GBK/UTF-8)、抓取网页正文或直接粘贴,AI 分段扫描自动提取**世界观、境界/等级体系、功法、材料物品、人物**,结果可逐条删改后一键写入当前书(自动去重)。可设置只扫前 N 万字,支持中断与断点续扫
- **大纲系统**:全书简介、各卷规划、章节细纲,层层支撑 AI 生成
- **AI 生成**(流式打字机效果,可随时停止):
  - 生成整章初稿 —— 结合细纲、前情、人物与世界观
  - 从光标续写 —— 手写到哪,AI 从光标位置接着往下写(接龙式共创)
  - 润色选中 —— 框选文字一键润色
  - 本章细纲 —— 一键生成分点情节细纲
  - 前情摘要 —— 写完一章点一次,自动浓缩存档
  - **自动连写多章** —— 设定章数,AI 按大纲+前情记忆逐章自动写完(只写空白章,不会覆盖你手写的内容;每写完一章自动生成前情摘要供后续章节使用;可随时停止)
- **前情记忆系统(长篇关键)**:生成第 N 章时自动组装「风格指令 + 本章细纲/意图 + 人物卡 + 世界观 + 最近章节原文节选 + 更早各章摘要」,按字符预算裁剪,**几十万字也不崩设定、不断前情**
- **爽文风格指令**:内置可编辑的网文写作 system prompt(短句快节奏、先抑后扬、章末钩子)
- **新设定自动入库**:每次「生成前情摘要」(自动连写时每章都会做一次)顺带逐段扫描本章正文,把**新人物、新物品、新境界、世界观补充**直接写进设定中心,按名称去重、不覆盖你已有的条目,并在状态提示里说明入库了哪些。设置页「设定自动入库」可关闭;关闭后仍可用「本章提取」手动归档。
- **导出 TXT**:全书按卷/章拼合,带保存对话框
- **自动保存 + 实时字数 + 深浅色主题**

## 快速开始

```bash
npm install
npm run dev        # 开发模式启动
npm run dist       # 打包 Windows 安装包(release/ 目录)
```

> 本项目开发时使用的是绿色版 Node.js(仓库内 `tools/nodejs`,版本 v22),系统 PATH 中若无 node,请先 `set "PATH=D:\项目\shu\tools\nodejs;%PATH%"`。
> 打包时 electron-builder 需要从 GitHub 下载二进制工具链,国内网络建议先设置镜像:
> `set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`

### 开发与测试

```bash
npm run typecheck  # TypeScript 类型检查(含 tests/)
npm test           # vitest 单元测试(切段/JSON 解析/存储/扫书状态机/store 切片)
npm run build      # 主/preload/renderer 三端产物(out/ 目录)
```

CI(GitHub Actions)对每次推送运行 typecheck + test + build;打 `v*` tag 时自动打包并发布 Release。

### 清理与卸载

本项目所有依赖与工具链都在项目文件夹内(`node_modules`、绿色版 `tools/nodejs`),**删除项目文件夹即可完全移除**,不残留系统级配置。应用产生的用户数据在以下两处,卸载后如不再需要请手动删除:

- 书库与书籍备份:默认 `文档\AINovelStudio\`(可在应用设置中自定义位置)
- 应用设置(含 safeStorage 加密的 API Key):`%APPDATA%\ai-novel-studio\settings.json`

### 配置 AI 模型(必须)

首次使用:右上角 **设置** → 选择服务商预设(或手填)→ 填入 **API Key** → **测试连接** → 保存。

支持**任意多个模型配置**:设置页点「新增」即可添加自命名配置(名称 / API 地址 / Key / 模型名全部自定义),点哪个配置就用哪个,适合同时挂官方 API + 中转站 + 本地模型随时切换。预设(智谱 / DeepSeek / Kimi / Ollama)只是快速填充模板,「自定义」模板则从空白开始,任何 OpenAI 兼容服务(中转站、one-api、new-api 等)都能接。

| 服务商 | API 地址 | 模型示例 | 密钥获取 |
|---|---|---|---|
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`(免费)/ `glm-4-plus` | open.bigmodel.cn |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | platform.deepseek.com |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | platform.moonshot.cn |
| Ollama(本地) | `http://localhost:11434/v1` | `qwen2.5:14b` | 无需密钥 |

任何兼容 OpenAI `/chat/completions` 流式接口的服务均可,直接改 API 地址和模型名即可。

## 界面与交互

顶部导航切换**三大工作区**,所有功能都有专属空间,不再挤在小标签里:

- **✍ 写作**:卷章树 + 编辑器 + AI 助手(面板宽度可拖动调节)三栏常驻,沉浸码字
- **🗂 设定中心**:人物 / 物品图鉴 / 世界观三列并排全宽展示,起名、建卡、提取物品都在各自列内完成
- **🗺 大纲规划**:全书简介 + 风格指令 + 各卷规划 + 章节细纲两栏编辑(左列表、右细纲),一屏规划整本书
- **🔍 扫书**:左侧导入来源(TXT/网页/粘贴)与扫描控制,右侧实时查看提取结果并逐条清理,一键写入当前书

其他交互:底部状态栏常显保存状态、本章/全书字数、当前模型、AI 忙碌状态;`Ctrl+S` 保存、`Esc` 关弹窗、`Ctrl+Enter`(意图输入框内)快速生成整章;AI 生成结果的操作按钮吸底常显。

## 推荐写作流程

1. **新建书籍**,在大纲规划页写清楚简介(主线 + 金手指)和风格指令
2. 切到设定中心:人物建卡(AI 起名)、物品建卡(AI 生成 / 本章提取)、世界观写清等级体系
3. 回到大纲规划:列好各卷剧情,把每章的细纲写好(章节名即大纲)
4. 回到写作区:AI 助手填一句**本章意图** → 「生成整章」;或直接「自动连写」挂机写完空白章
5. 结果可「插入到光标处」/「追加到正文末尾」/「替换整章」;写到哪里卡壳,光标停那里点「从光标续写」
6. 写完点「生成前情摘要」→ 后续章节自动携带前情,同时本章的新人物/新物品/新境界会自动进设定中心(自动连写模式每章自动完成)

## 目录结构

```
src/
  shared/types.ts       # 共享数据模型 + AI 服务商预设 + 默认风格指令
  main/                 # 主进程
    index.ts            # 窗口与生命周期
    ipc.ts              # IPC 接口(书籍/章节/设置/AI)
    storage.ts          # 本地文件存储(书库/章节/导出)
    ai-client.ts        # OpenAI 兼容流式客户端(SSE)
    context-builder.ts  # 前情记忆:上下文组装与预算裁剪
  preload/index.ts      # contextBridge API
  renderer/src/         # React 界面(三栏布局)
    store.ts            # 状态入口:组合 slices/ 六个领域切片
    slices/             # base 骨架 / chapters 章节 / codex 设定 / ai 生成 / inspire 陪聊 / importer 扫书
tests/                  # vitest 单元测试
tools/nodejs/           # 绿色版 Node(v22),仅供本仓库开发使用
```

## 界面设计规范 V3.1「纸面浮室」

渲染层视觉全部由 `src/renderer/src/index.css` 的 CSS 变量驱动,改观感只需调变量,不必动组件:

- **结构**:单条顶栏 + 内容区;AI 助手为右侧按需滑出的玻璃抽屉(`.drawer`,快捷键 Ctrl+I,生成时自动弹出);底部状态栏已并入正文画布内的静默统计条
- **表面**:`.editor-sheet` 写作纸面 / `.panel` 浮卡 / `.inset` 内嵌区 / `.soft-row` 列表软行 / `.glass` 玻璃浮层
- **质感来源**:环境光渐变底(`body::before`)+ 细噪点(`body::after`,2.8%)+ 层叠柔影 + 顶缘 1px 内高光(`--inset-light`)+ 主色渐变按钮(`.btn-primary`)
- **色彩**:浅色纸灰底、深色墨蓝底;朱砂红 `--accent` 仅用于点睛;深浅主题各一套变量,组件零改动切换
- **字体**:界面黑体(系统栈),手稿与标题用思源宋体 `Noto Serif SC`(经 `@fontsource/noto-serif-sc` 本地打包,SIL OFL 开源许可,许可文本见 `build/font-OFL.txt`);宋体/黑体的切换只需改 `--font-serif` 一个变量

## 数据格式

每本书一个目录(默认 `文档/AINovelStudio/<书名-短id>/`):

```
book.json            # 元数据、卷、人物、世界观、风格指令、章节元数据
chapters/ch-0001.json # { 标题, 细纲, 正文, 前情摘要, 字数, 时间戳 }
```

纯 JSON 文件,可直接备份、迁移或用其他工具处理。
